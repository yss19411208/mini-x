## 4. エンジニアに質問したい点の候補
1. **`server.ts` が 1 ファイルで約 790 行**あります。部屋・SSE・回数の制限・API を 1 つにまとめていますが、どこで分けるとよいでしょうか（分けると、部屋の Map などを渡し回すことになるのが迷いどころです）。
2. **ブラウザ向けの `.ts` を、頼まれたときに `Bun.Transpiler` で JavaScript に直して配っています**（ビルドの手順を増やさないため）。本番では、前もってビルドした `.js` を配るほうがよいでしょうか。React 版はビルドしたファイルをリポジトリに入れていますが、これも一般的でしょうか。
3. **夢のたまごは `setTimeout` でかえしていて、サーバーを再起動するとポストもたまごも消えます**（メモリだけ）。残すなら、ファイルや SQLite に書くとして、タイマーを起動のときに作り直すのがよいでしょうか。また、回数の制限を IP ごとにしているのは、学校など同じ IP の人が多い場所では厳しすぎないでしょうか。
