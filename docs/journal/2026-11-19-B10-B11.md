- `react/` に、本体と同じ機能（A 組の見た目・B1〜B4・B7〜B9）の React 版を作った。まず JSX（コミット `e5ccf0c`）、次に TSX

- 説明: `docs/explain.md` の「B10・B11」

## 判断と理由
- **JSX と TSX を両方残すか → TSX だけ残す**。同じ画面のコードが 2 つあると、直すときに片方を忘れる。JSX 版はコミットに残っているので、見たいときは `git show e5ccf0c` で見られる
- **React 版をどこで動かすか → ビルドして本体のサーバーから `/react/` で配る**
  - `bun run index.html`（3000 番）で動かすと、API は `localhost:8000` になる。8000 番には、前の作業の古いサーバーが残っていて止められなかったので、確かめると古いサーバーと話すことになった
  - 本体のサーバーから配れば、API は画面と同じ場所になる。本番でも React 版が見られ、本番のサーバーに React を入れる（`bun install`）必要もない
  - 代わりに、ビルドしたファイル（約 220KB）をリポジトリに入れることになる。`.gitattributes` で生成物の印を付けた
- **ファイルの名前を限る**: `/react/*` は URL の後ろをファイル名に使うので、`../` でほかのファイルを読まれないよう、英数字・ハイフン・拡張子（html・js・css・svg）だけにした
- **`--production` でビルド**: ふつうの `--minify` だと React の開発用の版が入って 440KB になった。`--production` で 217KB
- **StrictMode は使わない**: 開発中に effect を 2 回動かすので、SSE の接続が一瞬 2 本になる。後片づけは書いてあるので壊れはしないが、本体と比べるときに紛らわしいので外した
