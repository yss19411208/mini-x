## 判断と理由
- **判定の関数は 1 つのファイルにして、サーバーと画面の両方で使う**: 画面の案内とサーバーの判定がずれないように。画面には B6 で作った「.ts を JavaScript に直して配る」しくみで渡せた
- **漢字は使えないことにした**: 読み方を知るには辞書が要り、大きくなる。かなだけなら決まりが簡単で、説明もしやすい
- **濁点は区別する**（「が」→「か」は不可）: 遊び方によって違うが、いちばん簡単で間違えにくい決まりにした
- **「ん」で終わることばも保存する**: 負けたことが皆に見えるほうが面白い。次の人は好きな字から始められる
- **部屋は URL の `?room=` で選ぶ**: サーバーはもともと部屋ごとに分かれていたので、画面が部屋を選べるようにするだけで済んだ。いいねの記録（localStorage）も部屋ごとに分かれる
- **ホームの太字**: 前は `.nav-home` がいつも太字だった。今いる部屋を太字にするため `aria-current="page"` で決めるようにし、React 版の `index.html` にも `aria-current` を足した（太字が消えないように）
