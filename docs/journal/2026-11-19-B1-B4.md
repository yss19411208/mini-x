## 確かめた手順と結果（`bun --hot server.js`、ブラウザで画面を開く）
1. B1: 最初「140」。139 字＋絵文字 1 個で「0」、もう 1 字で「-1」が赤（`rgb(244, 33, 46)`）になりボタンが押せない。本文を消すと「140」に戻る → OK
2. B2: カードの名前の横に「4分前」など。マウスを乗せると「2026/11/19 16:00:24」。1 日より前の形は、時刻をずらして `formatTime` を呼んで「11/18 15:04」になるのを確かめた → OK
3. B3: 名前「B3check」本文を打って Ctrl+Enter（本物のキー入力）→ 先頭に出て本文が空・「140」に戻る。Ctrl+Enter を 3 回続けて送る → サーバーに 1 件だけ。変換中（`isComposing`）の Ctrl+Enter → 送られない → OK
4. B4: 名前と本文を書きかけのまま、別の人のポストをサーバーに直接送る → 10 秒以内にタイムラインの先頭に出た。書きかけの名前・本文・残りの文字数はそのまま。更新ボタン 5 連打 → 通信は 2 回、同時は最大 1 本 → OK
5. `bun test` → 10 pass / 0 fail。`server.js` の上限をわざと 141 にすると 1 fail（元に戻した）→ テストが効いている
